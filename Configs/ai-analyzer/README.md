# AI Alert Analyzer

This directory documents the custom AI-assisted alert analysis component developed for the GCP SOC Automation Lab.

## Role in the Architecture

The AI analyzer runs as a Python service on the Wazuh Manager and processes high-severity security alerts generated by Wazuh.

The workflow is:

**Wazuh Alert → Severity Filter → Deduplication → Vertex AI → Structured SOC Incident**

Only alerts meeting the configured severity threshold are submitted for AI-assisted analysis.

## AI Analysis

Google Cloud Vertex AI is used to analyze relevant Wazuh security alerts and return structured SOC investigation results.

The analyzer produces fields including:

- Verdict
- Risk
- Confidence
- Alert summary
- Trigger reason
- Evidence
- Investigation steps
- Recommended action

The AI output is validated and converted into a standardized incident object with a unique incident ID for traceability.

## Alert Processing

The analyzer includes logic for:

- High-severity alert filtering
- Event-specific deduplication
- Cooldown handling
- Microsoft Defender alert enrichment
- Sysmon alert processing
- Known-noise suppression
- Structured JSON validation
- Incident ID generation

This helps reduce duplicate/noisy processing while preserving security events that require investigation.

## Incident Distribution

After analysis, the structured incident is used across multiple components of the SOC pipeline:

- **JSONL** — Local incident persistence
- **Google Cloud Storage** — Incident archival
- **BigQuery** — Historical SOC analytics
- **Pub/Sub** — Event distribution
- **Shuffle SOAR** — Automated workflow execution
- **TheHive** — Alert and incident management

## Service Operation

The analyzer runs as a systemd service on the Wazuh Manager, allowing the analysis pipeline to operate continuously without requiring the Python script to be started manually.

## Security

The public configuration and code examples in this repository are sanitized.

Credentials, API keys, webhook identifiers, public IP addresses, service-account secrets, and other sensitive infrastructure values are excluded or replaced with placeholders.
