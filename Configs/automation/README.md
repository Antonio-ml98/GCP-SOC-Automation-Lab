# SOAR and Incident Response Automation

This directory documents the automation layer used in the GCP SOC Automation Lab.

## Role in the Architecture

Shuffle SOAR receives structured security incidents generated by the custom Wazuh AI alert analyzer.

The automation workflow connects the AI-assisted detection pipeline with TheHive for centralized alert and incident management.

The workflow is:

**Wazuh → Vertex AI Analyzer → Structured Incident → Shuffle SOAR → TheHive**

## Shuffle SOAR

Shuffle is used as the automation and orchestration platform for the project.

The AI analyzer sends the standardized incident object to a Shuffle webhook. The webhook triggers the configured workflow, which processes the incident data and forwards it to TheHive.

The workflow demonstrates:

- Webhook-based incident ingestion
- Automated workflow execution
- Dynamic incident-field mapping
- Integration with TheHive
- Automated alert creation

## TheHive Integration

TheHive is used as the incident and alert management platform.

A dedicated service account and organization-level profile were configured for the Shuffle integration with the required alert-creation permission.

Incident information forwarded from Shuffle includes fields such as:

- Incident ID
- Alert summary
- Severity and risk context
- Source information
- Evidence
- Investigation steps
- Recommended action

This allows AI-assisted Wazuh detections to enter an incident-management workflow without requiring manual alert creation.

## End-to-End Automation

The completed automation path is:

**Windows Endpoint → Microsoft Defender / Sysmon → Wazuh → Vertex AI → Structured Incident → Shuffle → TheHive**

The same structured incident is also persisted and distributed through JSONL, Google Cloud Storage, BigQuery, and Pub/Sub.

## Security

Public examples in this directory are sanitized before publication.

The following values are intentionally excluded or replaced with placeholders:

- API keys
- Passwords
- Shuffle webhook identifiers
- Public IP addresses
- Authentication tokens
- Other sensitive infrastructure values

Original Shuffle and TheHive configuration files containing credentials remain private and are not included in this repository.
