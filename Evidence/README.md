# Project Evidence

This directory contains implementation and validation evidence collected throughout the GCP SOC Automation Lab.

The screenshots document the project from initial GCP deployment through endpoint telemetry, Wazuh detection, AI-assisted alert analysis, automated incident processing, SOAR integration, and cloud-based storage and analytics.

## Evidence Coverage

- GCP environment and Wazuh deployment
- Windows 10 Wazuh Agent and Sysmon integration
- Microsoft Defender and EICAR detection testing
- Wazuh alert generation and custom detection rules
- Vertex AI-assisted SOC alert analysis
- Structured incident generation and persistence
- TheHive deployment and incident management
- Shuffle SOAR deployment and automation
- Automated Shuffle → TheHive incident workflow
- Google Cloud Pub/Sub integration
- BigQuery incident storage
- Cloud Storage (GCS) archival
- Final end-to-end SOC automation validation

> Screenshots are provided as implementation evidence. Sensitive credentials, API keys, passwords, and secrets are intentionally excluded.
